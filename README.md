# 三角形 ABC の x 軸回転 Web アプリ

## 概要

この Web アプリは、空間内の三角形 \(ABC\) の周および内部を **x 軸のまわりに回転**させたときに通過する領域を、ブラウザ上で 3 次元的に観察するための教材です。

三角形の頂点は次のとおりです。

- \(A=(2,1,2)\)
- \(B=(0,3,0)\)
- \(C=(0,-3,0)\)

## 主な機能

- 回転角を \(0^\circ\) から \(360^\circ\) までスライダーで変更
- 回転アニメーションの再生・停止
- マウス操作による視点変更
- マウスホイールによる拡大・縮小
- 元の三角形の表示・非表示
- 回転面のメッシュ表示・非表示
- 座標軸の表示・非表示
- 回転の分割数の調整

## 座標系と視点

- 右手系を使用します。
- 右手系の関係は \(\boldsymbol e_x \times \boldsymbol e_y = \boldsymbol e_z\) です。
- 初期視点では、z 軸が上向き、x 軸の正方向が手前側に見えるように設定しています。
- y 軸は、ユーザーが希望した向きに見えるよう視点を調整しています。
- 視点の変更は表示上の調整であり、頂点の座標値や回転計算の定義は変更しません。
- 回転は x 軸まわりに行い、回転角の正方向は右手系に基づきます。

## 起動方法

1. `triangle_abc_x_rotation.html` をダウンロードします。
2. ファイルを Microsoft Edge または Google Chrome で開きます。
3. 画面左側のスライダーやチェックボックスを使って表示を調整します。

サーバーへのアップロードや追加ソフトのインストールは不要です。HTML ファイルをローカルで開いて利用できます。

## 操作方法

| 操作 | 方法 |
|---|---|
| 回転角の変更 | 「回転角」スライダーを動かす |
| 回転アニメーション | 「回転アニメーション」ボタンを押す |
| アニメーション停止 | 再生中に同じボタンを押す |
| 視点の回転 | 表示領域をマウスでドラッグ |
| 拡大・縮小 | 表示領域上でマウスホイールを操作 |
| 三角形の表示切り替え | 「元の三角形を表示」を切り替える |
| メッシュの表示切り替え | 「回転面のメッシュを表示」を切り替える |
| 座標軸の表示切り替え | 「座標軸を表示」を切り替える |
| 初期状態に戻す | 「初期表示に戻す」ボタンを押す |

## 回転の計算

x 軸まわりに角度 \(\theta\) だけ回転すると、点 \((x,y,z)\) は次の点に移ります。

\[
(x,y,z) \longmapsto
\left(
x,\,
y\cos\theta-z\sin\theta,\,
y\sin\theta+z\cos\theta
\right)
\]

この式は右手系に基づく x 軸まわりの回転です。

## 表示上の注意

このアプリは、回転によってできる領域の形状を視覚的に理解するための教材用の可視化です。回転領域は点群や境界面をサンプリングして描画しているため、表示の細かさや角度によっては、立体の境界が完全に滑らかに見えないことがあります。回転の分割数を増やすと描画が細かくなりますが、処理負荷も増加する場合があります。
