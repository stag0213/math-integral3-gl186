# 三角形ABCをx軸のまわりに1回転してできる立体の可視化

空間内の3点 A(2, 1, 2)、B(0, 3, 0)、C(0, −3, 0) を頂点とする三角形ABC（周と内部）を、x軸のまわりに1回転させたときに通過してできる立体を、3Dで表示するWebアプリです。

HTMLファイル1つで動きます。ビルドやインストールは要りません。

## 動作環境

- WebGLに対応したブラウザ（Chrome、Edge、Firefox、Safari の最新版）
- インターネット接続（Three.js と KaTeX を CDN から読み込むため）

## 使い方

1. `index.html` を任意のフォルダに保存します。
2. ブラウザで `index.html` を開きます（ダブルクリック、またはブラウザへドラッグ＆ドロップ）。

ES Modules と import map を使っています。ローカルファイルとして開いて表示されないブラウザでは、簡易サーバーを立てて開いてください。

```bash
# Python がある場合
python -m http.server 8000
# ブラウザで http://localhost:8000/index.html を開く
```

## 機能

| 機能 | 内容 |
| --- | --- |
| 3D表示 | ドラッグで視点を回転、ホイールで拡大・縮小、右ドラッグで平行移動 |
| 回転角スライダー | 三角形を回転角 θ（0°〜360°）まで回した状態を表示 |
| 回転アニメーション | 三角形が x軸のまわりを1周する様子を再生。通過した場所の残像と頂点 A, B, C の軌跡（円）を描画 |
| 立体の表示 | 外側の面と内側の面から作った回転体を半透明で表示 |
| 断面カット | 立体の 1/4 を切り取り、内部の空洞と切り口の形を表示 |
| ワイヤーフレーム | 立体をワイヤーフレームで表示 |
| 不透明度 | 立体の不透明度を 0.1〜1 で調整 |
| 切断面スライダー | 平面 x = c（0 ≤ c ≤ 2）による切り口の円環を3D空間に表示 |
| 断面図（右上） | x = c での切り口を yz 平面で表示。回転中の線分、内半径 r、外半径 R を描画 |
| 数式表示 | 外半径・内半径・断面積・体積の式と値を KaTeX で表示。値はリアルタイムで更新 |

## 数学的な解説

### 切り口の線分

辺AB、ACはそれぞれ次のように表せます。

- AB：$(t,\ 3-t,\ t)$
- AC：$(t,\ 2t-3,\ t)$　$(0 \le t \le 2)$

三角形を平面 $x = t$ で切ると、切り口はこの2点を結ぶ線分になります（$z = t$ で一定、$y$ は $2t-3$ から $3-t$ まで）。

### 外半径と内半径

この線分を x軸のまわりに回すと、切り口は円環になります。

外半径は、x軸から最も遠い点 $(t,\ 3-t,\ t)$ までの距離です。

$$R(t) = \sqrt{(3-t)^2 + t^2}$$

内半径は、x軸から最も近い点までの距離です。

- $0 \le t \le \frac{3}{2}$ のとき：線分が $y = 0$ をまたぐので、最も近い点は $(t,\ 0,\ t)$ です。

$$r(t) = t$$

- $\frac{3}{2} \le t \le 2$ のとき：最も近い点は端点 $(t,\ 2t-3,\ t)$ です。

$$r(t) = \sqrt{(2t-3)^2 + t^2}$$

### 断面積

$$S(t) = \pi\{R(t)^2 - r(t)^2\} =
\begin{cases}
\pi(3-t)^2 & \left(0 \le t \le \frac{3}{2}\right) \\
\pi(-3t^2 + 6t) & \left(\frac{3}{2} \le t \le 2\right)
\end{cases}$$

### 体積

$$V = \pi\int_0^{\frac{3}{2}} (3-t)^2\,dt + \pi\int_{\frac{3}{2}}^{2} (-3t^2 + 6t)\,dt
= \frac{63}{8}\pi + \frac{5}{8}\pi = \frac{17}{2}\pi \approx 26.704$$

### 立体の形

- 外側の面は、線分ABを x軸のまわりに回転させた曲面です。
- 内側には空洞があります。$0 \le x \le \frac{3}{2}$ では円錐状（$r = x$）、$\frac{3}{2} \le x \le 2$ では線分ACの一部を回転させた曲面になります。

## 実装の概要

| 項目 | 内容 |
| --- | --- |
| 3D描画 | [Three.js](https://threejs.org/) r160 |
| 視点操作 | `OrbitControls` |
| 3Dラベル | `CSS2DRenderer`（頂点名・軸名） |
| 回転体 | `LatheGeometry` に外半径 R(x) と内半径 r(x) の輪郭を与えて生成し、回転軸を x軸に合わせる |
| 断面カット | 回転角を 270° にした `LatheGeometry` と、`ShapeGeometry` による切り口の面 |
| 切断面 | `RingGeometry`（内半径 r、外半径 R） |
| 断面図 | Canvas 2D |
| 数式表示 | [KaTeX](https://katex.org/) 0.16.11 |

座標系は z軸が上向きになるようにしています（`camera.up = (0, 0, 1)`）。

## カスタマイズ

- **頂点の座標を変える**：`const A=..., B=..., C=...` を書き換えます。あわせて、関数 `Rf`・`rf`、切断線分の端点、スライダーの範囲、数式表示も変更が必要です。
- **色を変える**：各 `Material` の `color` を変更します。
- **アニメーションの速さを変える**：`loop()` 内の `theta+1.2` の値を変更します。

## 注意事項

- オフライン環境では動きません。CDNのファイルを手元に置き、パスを書き換えれば動くようになります。
- 古いブラウザでは import map に対応しておらず、動かない場合があります。
